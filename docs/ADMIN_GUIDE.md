# Admin Guide

Access `/admin` with an editor or admin account.

## Sections

| Section | Actions |
|---------|---------|
| Pending Updates | Approve/reject scraper updates |
| Submissions | Approve/reject/publish user content |
| Analytics | Page views, ad clicks, payments, leads |
| Users | Search, filter, change roles, ban/unban, verify email |
| Content | View published content (edit in Sanity Studio) |
| Ads | Create, edit, delete ad placements |

## Roles

| Role | Access |
|------|--------|
| `reader` | Public content and account |
| `editor` | Review updates, manage content, admin dashboard |
| `admin` | Full admin including user management |
| `superadmin` | System configuration |

## Notifications

Editors receive Discord notifications when the scraper finds updates.
